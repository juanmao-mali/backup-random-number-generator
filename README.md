# 可爱随机数生成器 🎲

一个简单而可爱的随机数生成器，可以生成 1-100 之间不重复的随机数。

## 功能特点

- 🎯 生成 1-100 之间的随机数
- 🔄 确保数字不重复出现
- 🎨 可爱的用户界面设计
- 🎮 简单的开始/停止控制
- 📱 响应式设计，支持移动设备

## 使用方法

1. 点击"开始"按钮，数字会开始快速变化
2. 点击"停止"按钮，会停在当前数字
3. 已经出现过的数字不会再次出现
4. 当所有数字都被使用后，会显示提示信息

## 技术栈

- HTML5
- CSS3
- JavaScript

## 本地运行

1. 克隆仓库到本地
2. 直接在浏览器中打开 `index.html` 文件即可使用
